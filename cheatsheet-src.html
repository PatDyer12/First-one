1. CAUSALITY — does X actually cause Y?

Symbols
$Y_i(1)$person $i$'s outcome if treated
$Y_i(0)$person $i$'s outcome if not treated
$D_i$treatment: 1 = treated, 0 = not treated
$\tau_i$ (“tau”)person $i$'s treatment effect

Individual effect: $\tau_i = Y_i(1) - Y_i(0)$

ATE (average treatment effect) = average of $\tau_i$ over everyone

ATT (effect on the treated) = average of $\tau_i$ over treated people only

The key equation:

Observed gap $=$ ATT $+$ Selection bias

Observed gap $= E[Y(1)\mid D{=}1] - E[Y(0)\mid D{=}0]$

Selection bias $= E[Y(0)\mid D{=}1] - E[Y(0)\mid D{=}0]$

selection bias asks: were the treated people already different, even without treatment?

Steps for a potential-outcomes table

  1. $\tau$ for each row $= Y(1) - Y(0)$
  2. ATE = average $\tau$ of all rows
  3. Observed gap = avg $Y(1)$ of treated rows − avg $Y(0)$ of untreated rows
  4. ATT = average $\tau$ of treated rows
  5. Selection = avg $Y(0)$ of treated − avg $Y(0)$ of untreated
  6. Check: ATT + Selection = Observed gap

Big ideas

  • Fundamental problem of causal inference: we only ever see ONE outcome per person (treated or not). The other one — what would have happened — is the counterfactual, and it's missing.
  • Randomized experiment (RCT): chance decides who is treated, so the groups are alike on average → selection bias $=0$ → (treatment avg − control avg) estimates the ATE.
  • RCT problems: dropouts/non-compliance, cost, ethics, may not apply elsewhere (external validity).
  • Correlation ≠ causation (and prediction ≠ causation). Other reasons X and Y move together: Y causes X (reverse causality); a third factor drives both (confounder); both just trend over time; pure chance.
  • Deterministic: Y is known exactly from X (°F = 1.8·°C + 32). Stochastic: $Y=\beta_0+\beta_1X+u$ — there's a random part $u$.

2. PROBABILITY & STATISTICS

Symbols
$X$ vs. $x$random variable (not known yet) vs. an actual value
$\mu$ (“mu”) $=E[X]$population mean (expected value)
$\sigma^2$ (“sigma sq.”)population variance; $\sigma$ = standard deviation
$\bar X$ (“X-bar”), $n$sample mean, sample size
$s^2,\ s$sample variance, sample SD

PMF = the table of $P(X=x)$. Valid if every value is $\ge 0$ and they add to 1.

CDF $F(x)=P(X\le x)$ = running total. Looks like a staircase: flat between values, jumps up at each value.

$P(X>x) = 1-F(x)$    $P(X\ge 2)=1-P(X\le 1)$

Mean: $E[X] = \sum x\cdot P(X=x)$

Variance: $\text{Var}(X) = E[X^2] - (E[X])^2$, with $E[X^2]=\sum x^2 \cdot P(X=x)$

SD $=\sqrt{\text{Var}}$ — same units as $X$ (variance is in units²)

mean = probability-weighted average; SD = typical distance from the mean.

If $C = a + bX$ (e.g. $C = 30 + 8X$):

$E[C] = a + b\,E[X]$    $\text{Var}(C) = b^2\,\text{Var}(X)$    $\text{SD}(C)=|b|\,\text{SD}(X)$

adding a constant moves the mean but not the spread.

Sample statistics (from a list of numbers)

$\bar x = \dfrac{\text{sum}}{n}$     $s^2 = \dfrac{\sum (x_i-\bar x)^2}{n-1}$   ← divide by $n-1$, not $n$

Steps for $s^2$: find the mean → subtract it from each value → square each → add up → divide by $n-1$. Then $s=\sqrt{s^2}$.

Median = middle value once sorted. Mode = most common. Change units (multiply every value by $c$, e.g. minutes → seconds, $c=60$): mean, median, SD all $\times c$; variance $\times c^2$.

Covariance & correlation

$\text{Cov}(X,Y) = E[XY] - E[X]E[Y]$   + means they move together, − means opposite.

$\text{Corr} = \rho = \dfrac{\text{Cov}(X,Y)}{\sigma_X\,\sigma_Y}$   always between −1 and 1, no units.

Corr = 0 only means no straight-line relationship. Example: $Y=X^2$ with $X$ centered at 0 has Corr = 0 but $Y$ depends completely on $X$.

Conditional probability

$P(A\mid B) = \dfrac{P(A \text{ and } B)}{P(B)}$

“out of the B cases, what share are also A?” — B is the reference group. In a 2×2 table: “A and B” = inside cell, $P(B)$ = its total.

Independent if $P(A \text{ and } B) = P(A)\cdot P(B)$  (same as $P(A\mid B)=P(A)$)

0/1 variables R and L: $E[RL] = P(\text{both}=1)$, so $\text{Cov} = P(\text{both}) - P(R)P(L)$. Positive Cov still doesn't prove causation.

3. THE NORMAL DISTRIBUTION

$N(20,\,5^2)$ means SD = 5 (the 2nd number is the VARIANCE).

Step 1: z-score (# of SDs from mean):   $z = \dfrac{x-\mu}{\sigma}$

Step 2: look up $\Phi(z)=P(Z\le z)$ (“phi”) in the table and use:

$P(X\le b)=\Phi(z_b)$    $P(X> b)=1-\Phi(z_b)$

$P(a\le X\le b)=\Phi(z_b)-\Phi(z_a)$    $\Phi(-z)=1-\Phi(z)$

68–95–99.7 rule: about 68% within 1 SD of the mean, 95% within 2 SD, 99.7% within 3 SD. 95% range ≈ $\mu \pm 2\sigma$.

Why $P(X = 20) = 0$: for a continuous variable, probability = area under the curve. A single point has no width → zero area. A range like 19 to 21 has width → positive area.

4. ESTIMATORS — how good is a guess?

Symbols
$\theta$ (“theta”)the true unknown number we want
$\hat\theta$ (“theta-hat”)our guess of it, from the sample
$p$true probability (e.g. chance of heads)
$S$, $\hat p=S/n$number of 1s in sample; sample share

Estimator = the formula/rule (random — changes from sample to sample). Estimate = the actual number you get from your data.

Bias $= E[\hat\theta] - \theta$.  Unbiased = right on average.

Efficient: among unbiased ones, the one with smaller variance.

Consistent: gets closer to the truth as $n$ grows (bias → 0 and variance → 0).

MSE $=\text{Variance} + \text{Bias}^2$   (lower is better)

a little bias can be worth it if the variance drops a lot.

Tools: $E[\bar X]=\mu$,  $\text{Var}(\bar X)=\sigma^2/n$. For 0/1 data: $E[S]=np$,  $\text{Var}(S)=np(1-p)$.

5. REGRESSION (OLS)

Symbols
$Y$outcome (dependent variable)
$X$explanatory variable (independent / regressor)
$\beta_0,\ \beta_1$ (“beta”)TRUE intercept and slope (unknown)
$u$error: everything else that affects $Y$
$\hat\beta_0,\ \hat\beta_1$our estimated intercept and slope
$\hat y$ (“y-hat”)predicted value on the line
$\hat u$ (“u-hat”)residual = actual − predicted $= y-\hat y$

Model: $Y = \beta_0 + \beta_1 X + u$.  OLS picks the line that makes the sum of squared residuals as small as possible.

$\hat\beta_1 = \dfrac{\sum (x_i-\bar x)(y_i-\bar y)}{\sum (x_i-\bar x)^2}$     $\hat\beta_0 = \bar y - \hat\beta_1\,\bar x$

Also $\hat\beta_1 = r\cdot\dfrac{s_Y}{s_X}$ → slope has the same sign as the correlation.

Steps by hand

  1. Find $\bar x$ and $\bar y$.
  2. Make columns: $x-\bar x$,  $y-\bar y$,  $(x-\bar x)^2$,  $(x-\bar x)(y-\bar y)$.
  3. Add up the last two columns → plug into $\hat\beta_1$, then $\hat\beta_0$.
  4. Predicted: $\hat y = \hat\beta_0+\hat\beta_1 x$. Residual: $\hat u = y-\hat y$.
  5. Check: residuals add to 0, and $\sum x\hat u = 0$.

Where formulas come from: minimize $Q=\sum (y_i-b_0-b_1x_i)^2$ (squared so + and − misses don't cancel). Set derivatives to 0:

$\frac{\partial Q}{\partial b_0} = -2\sum(y_i-b_0-b_1x_i)=0$ → $\sum \hat u_i = 0$

$\frac{\partial Q}{\partial b_1} = -2\sum x_i(y_i-b_0-b_1x_i)=0$ → $\sum x_i\hat u_i = 0$

Divide the first by $n$: $\bar y = \hat\beta_0 + \hat\beta_1\bar x$ → the line always passes through $(\bar x,\bar y)$.

Changing units: multiply $y$ by $c$ → slope and intercept both $\times c$. Multiply $x$ by $c$ → slope $\div c$, intercept same. (Dollars → cents: slope $\times 100$.)

How to interpret (fill in the blanks)

Slope: “Each additional [unit of X] is associated with a $\hat\beta_1$ [units of Y] change in Y, on average.”

Intercept: predicted Y when X = 0 (often meaningless if X = 0 is outside the data).

Prediction: plug x into $\hat y=\hat\beta_0+\hat\beta_1x$.

Not causal because: units with more X may differ in other ways (ability, income) that sit in $u$; no random assignment.

Key assumption: $E[u\mid X]=0$

the “other factors” average out to zero at every value of X.

If true, the line gives the average Y at each X. You don't need it just to calculate $\hat\beta$ — only to interpret it. It fails if, e.g., family income affects test scores AND is related to class size.

Residuals always adding to 0 is just math — it does not prove $E[u\mid X]=0$.

Reading R output: the “Estimate” column gives the line, e.g. $\widehat{\text{Score}} = 698.93 - 2.28\cdot\text{ClassSize}$. Degrees of freedom $= n-2$, so 418 df → $n = 420$.
