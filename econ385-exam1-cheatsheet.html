1. CAUSALITY — does X actually cause Y?

Individual effect: τi=Yi(1)−Yi(0)\tau_i = Y_i(1) - Y_i(0)τi​=Yi​(1)−Yi​(0)

ATE = average of τi\tau_iτi​ over everyone.  ATT = average of τi\tau_iτi​ over treated people only.

Observed gap === ATT +++ Selection bias

Observed gap =E[Y(1)∣D=1]−E[Y(0)∣D=0]= E[Y(1)\mid D{=}1] - E[Y(0)\mid D{=}0]=E[Y(1)∣D=1]−E[Y(0)∣D=0]

Selection bias =E[Y(0)∣D=1]−E[Y(0)∣D=0]= E[Y(0)\mid D{=}1] - E[Y(0)\mid D{=}0]=E[Y(0)∣D=1]−E[Y(0)∣D=0]

were the treated people already different, even without treatment?

STEPS: potential-outcomes table (Practice Q1)
  1. New column: τ=Y(1)−Y(0)\tau = Y(1) - Y(0)τ=Y(1)−Y(0) for every row.
  2. ATE = average τ\tauτ of all rows.
  3. Observed gap = avg Y(1)Y(1)Y(1) of treated (“Yes”) rows − avg Y(0)Y(0)Y(0) of untreated (“No”) rows.
  4. Compare: observed gap ≠ ATE → selection bias is present.
  5. ATT = average τ\tauτ of treated rows only.
  6. Selection = avg Y(0)Y(0)Y(0) of treated − avg Y(0)Y(0)Y(0) of untreated.
  7. Check: ATT + Selection = Observed gap.
  • Fundamental problem of causal inference: we only see ONE outcome per person; the other (the counterfactual) is missing.
  • Random assignment (RCT): groups alike on average → selection bias =0=0=0 → treatment mean − control mean estimates the ATE. More credible because no one chooses their group.
  • Correlation ≠ causation: reverse causality (Y causes X); a confounder drives both; chance.
  • Prediction ≠ policy: X can predict Y by tracking hidden factors; changing X by policy doesn't change them.
  • Deterministic: Y exact from X (°F = 1.8·°C + 32). Stochastic: Y=β0+β1X+uY=\beta_0+\beta_1X+uY=β0​+β1​X+u (random part uuu).

4. ESTIMATORS — how good is a guess?

Estimator = the formula/rule (random). Estimate = the number you get from your data.

Bias =E[θ^]−θ= E[\hat\theta] - \theta=E[θ^]−θ. Unbiased = right on average.  Efficient: among unbiased, smaller variance.

Consistent: closer to the truth as nnn grows (bias → 0 and variance → 0).  MSE =Var+Bias2=\text{Var} + \text{Bias}^2=Var+Bias2 (lower is better).

5. REGRESSION (OLS)

Model: Y=β0+β1X+uY = \beta_0 + \beta_1 X + uY=β0​+β1​X+u.  OLS = the line with the smallest sum of squared residuals.

β^1=∑(xi−xˉ)(yi−yˉ)∑(xi−xˉ)2\hat\beta_1 = \dfrac{\sum (x_i-\bar x)(y_i-\bar y)}{\sum (x_i-\bar x)^2}β^​1​=∑(xi​−xˉ)2∑(xi​−xˉ)(yi​−yˉ​)​     β^0=yˉ−β^1 xˉ\hat\beta_0 = \bar y - \hat\beta_1\,\bar xβ^​0​=yˉ​−β^​1​xˉ

Also β^1=r⋅sYsX\hat\beta_1 = r\cdot\dfrac{s_Y}{s_X}β^​1​=r⋅sX​sY​​ → slope has the same sign as the correlation.

  3. Add up the last two columns → β^1\hat\beta_1β^​1​ = (last column sum) ÷ ((x−xˉ)2(x-\bar x)^2(x−xˉ)2 column sum).
  4. Write β^0=yˉ−β^1xˉ\hat\beta_0=\bar y-\hat\beta_1\bar xβ^​0​=yˉ​−β^​1​xˉ with letters, THEN plug in numbers.

Intercept: predicted Y when X = 0 (often meaningless if X = 0 is outside the data).
