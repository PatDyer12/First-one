1 · CAUSALITY (Rubin potential outcomes)

Yi(1) = outcome if treated, Yi(0) = if not. Di=1 treated. Observed: Yi = DiYi(1) + (1−Di)Yi(0).

Individual effect τi = Yi(1) − Yi(0)  (heterogeneous: τi ≠ τj)

ATE = E[Y(1)−Y(0)] = avg τ over everyone = E[Y(1)]−E[Y(0)]

ATT = E[Y(1)−Y(0) | D=1] = avg τ over treated only

Observed diff E[Y(1)|D=1] − E[Y(0)|D=0]
 = ATT + Selection bias {E[Y(0)|D=1] − E[Y(0)|D=0]}
Selection bias = how treated would've done WITHOUT treatment vs. controls. >0 ⇒ observed gap overstates effect.

Table recipe: (1) τ each row (2) ATE = mean τ all rows (3) Observed = mean Y(1) of D=1 rows − mean Y(0) of D=0 rows (4) ATT = mean τ of D=1 rows (5) Sel = mean Y(0) of D=1 − mean Y(0) of D=0 (6) CHECK ATT+Sel = Observed. Slides ex: 35.75 = 20.75 + 15; ATE=17.5

Fundamental problem of causal inference (Holland 1986): observe at most ONE potential outcome per unit at a time; the other is the counterfactual (missing). Clones = perfect control (thought experiment).

RCT: random assignment ⇒ D ⊥ (Y(0),Y(1)) ⇒ E[Y(0)|D=1]=E[Y(0)|D=0] ⇒ selection = 0 ⇒ ȲT − ȲC estimates ATE (=ATT). Control group stands in for treated's missing Y(0). Balances traits in expectation (not clones; small samples can be unbalanced by chance).

RCT limits: noncompliance, attrition, spillovers, subjects know they're studied, small-sample imbalance, cost/ethics/infeasible, external validity, short run only.

No RCT? Natural expt / quasi-expt / observational. Draft lottery (Angrist ’90), quarter of birth IV (Angrist–Krueger ’91), Indonesia schools (Duflo ’01), Mariel boatlift (Card ’90), NJ vs PA min wage DiD (Card–Krueger ’94), close elections RD (Lee ’08), Oregon Medicaid lottery. LaLonde ’86: observational methods failed to match RCT.

Why X,Y correlate: X→Y causal; reverse Y→X; confounder Z→both; selection; common time trends; chance/data mining (spurious: margarine–divorce r=.99). Correlation = symmetric, descriptive; causation = directional, needs counterfactual + design.

Prediction vs policy: X can predict Y well as a proxy for confounders; intervening on X doesn't move the confounders ⇒ good forecast ≠ causal effect.

Deterministic Y=f(X) exactly (F=9/5·C+32; tax=τ·price; dist=speed·time; C=30+8X). Stochastic Y=β0+β1X+u (wage on educ): same X, different Y. Econometrics = stats + econ theory + math (Frisch 1933).

2 · PROBABILITY & STATS

RV maps outcomes→numbers (X: Ω→ℝ). Capital X = random; lowercase x = realized. Discrete (countable) vs continuous (interval).

PMF p(x)=P(X=x); valid iff all p ≥ 0 AND Σp = 1. CDF F(x)=P(X≤x)=Σt≤xp(t). Discrete CDF = step function: flat between values, jumps = p(x) at each value; 0 left of min, 1 at/after max; never decreases.

P(X>x)=1−F(x); P(a<X≤b)=F(b)−F(a); P(X≥2)=1−P(X≤1).

E[X] = Σ x·p(x)   E[X²] = Σ x²·p(x)
Var(X) = E[(X−μ)²] = E[X²] − (E[X])²   SD = √Var
E[a+bX] = a+bE[X];   Var(a+bX) = b²Var(X);   SD(a+bX)=|b|SD
Var(X±Y)=VarX+VarY±2Cov; indep ⇒ Cov=0
Indicator D∈{0,1}: E[D]=P(D=1)=p, Var=p(1−p)

Units: E, SD, median = units of X; Var = units². +a shifts center only (spread unchanged).

Mean (uses all, outlier-sensitive), median (middle; robust), mode (most frequent). Right skew ⇒ mean > median.

Sample statistics (use n−1!)

X̄ = Σxi/n;   s² = Σ(xi−x̄)²/(n−1); s=√s². n−1 because x̄ used up 1 df (corrects downward bias). Population: μ, σ², ρ, N (fixed, unknown). Sample: X̄, s², r, n (random).

Rescale data by c (e.g. min→sec c=60): mean×c, median×c, SD×c, var×c². Add a: mean+a, var same.

Covariance & correlation

Cov(X,Y) = E[(X−μX)(Y−μY)] = E[XY]−E[X]E[Y]; sample sXY=Σ(x−x̄)(y−ȳ)/(n−1). Cov(X,X)=Var X. Cov(a+bX,c+dY)=bd·Cov (unit-dependent).

Corr ρ = Cov/(σXσY), ∈[−1,1], unit-free, symmetric; mult. one var by negative flips sign. Corr=0 ≠ no relationship: X symmetric about 0, Y=X² ⇒ Cov=E[X³]=0 but perfectly dependent (only LINEAR assoc. measured). Corr ≠ causation.

Conditional probability / joint tables

P(A|B) = P(A∩B)/P(B) — denominator = reference group (“among B cases…”). Marginals = row/col totals. P(A|B) ≠ P(B|A) generally.

Independent iff P(A∩B)=P(A)P(B) ⇔ P(A|B)=P(A). Show one numeric comparison. Indicators R,L: E[RL]=P(R=1,L=1); Cov(R,L)=P(both)−P(R)P(L). Cov>0 = occur together, NOT causal.

Prediction w/ 0.5 cutoff: predict yes if P>.5; accuracy = share correct. Conditioning on informative var improves forecasts.

3 · CONTINUOUS & NORMAL

PDF f(x)≥0, total area 1; P(a≤X≤b) = area = ∫f. P(X=c)=0 (point has zero width) but interval has positive area ≈ f·width; density height can exceed 1 (not a prob). Endpoints don't matter: P(a<X<b)=P(a≤X≤b).

X ~ N(μ, σ²) — 2nd number is VARIANCE (N(20,5²) ⇒ σ=5)
Z = (X−μ)/σ ~ N(0,1); z = # SDs from mean (unit-free, compare across dists)
P(X≤b)=Φ(zb);   P(X>b)=1−Φ(zb);   P(a≤X≤b)=Φ(zb)−Φ(za)
Φ(−z) = 1−Φ(z);   P(−k≤Z≤k) = 2Φ(k)−1; symmetric, mean=median=mode

4 · ESTIMATORS

Estimator θ̂=g(X1..Xn) = a RULE, random variable w/ sampling distribution. Estimate = the NUMBER from one observed sample. Parameter θ fixed, unknown.

Bias = E[θ̂] − θ  (unbiased: E[θ̂]=θ, cluster centered on bullseye)
Efficiency: among UNBIASED estimators, smaller Var wins
Consistent: P(|θ̂n−θ|>ε)→0 as n→∞. Check: Bias→0 AND Var→0
MSE = E[(θ̂−θ)²] = Var(θ̂) + Bias² (small bias OK if Var drops a lot; ranking depends on true θ)

Tools (iid): E[X̄]=μ, Var(X̄)=σ²/n, SD(X̄)=σ/√n; E[ΣX]=nμ, Var(ΣX)=nσ². E[cθ̂]=cE[θ̂], Var(cθ̂)=c²Var(θ̂). Constants add to E only.
Bernoulli(p): E[Xi]=p, Var=p(1−p). S=ΣXi: E[S]=np, Var(S)=np(1−p).

General: θ̂=(aS+b)/c ⇒ E=(a·np+b)/c, Var=a²·np(1−p)/c².

5 · SIMPLE REGRESSION (OLS)

Population: Y = β0 + β1X + u. Y dependent/outcome/LHS; X regressor/RHS. β's fixed, unknown. u = all other determinants + nonlinearity + measurement error (unobserved).

Zero conditional mean E[u|X=x]=0: among units with same X, unobservables average 0 ⇒ E[Y|X=x]=β0+β1x (line = conditional mean); β1 = change in E[Y|X] per +1 X. u⊥X & E[u]=0 is stronger/sufficient. NOT needed to CALCULATE OLS — only to INTERPRET (only need variation in x).

OVB story: income ∈ u, affects score, correlated w/ class size ⇒ E[u|STR]≠0 ⇒ slope mixes STR effect with income ⇒ not causal (still valid description).

OLS: choose b0,b1 to min Q=SSR=Σ(yi−b0−b1xi)². Why squares: Σû cancels (+8,−8); squares smooth/differentiable, closed form, penalize big misses, target cond. mean. |û| → median regression, not diff. at 0.

FOCs: ∂Q/∂b0 = −2Σ(yi−b0−b1xi)=0 ⇒ Σûi=0 ⇒ ȳ=β̂0+β̂1x̄ ⇒ line passes through (x̄,ȳ).
∂Q/∂b1 = −2Σxi(yi−b0−b1xi)=0 ⇒ Σxiûi=0. These are algebraic sample identities; they hold always and do NOT prove population E[u|X]=0.

β̂1 = Σ(xi−x̄)(yi−ȳ) / Σ(xi−x̄)² = sXY/s²X = rXY·sY/sX
  = (Σxy − nx̄ȳ)/(Σx² − nx̄²)    β̂0 = ȳ − β̂1x̄

sign(β̂1) = sign(r) = sign(Cov) since sX,sY>0. Residual ûi=yi−ŷi (units of Y; + = point above line).

Hand-calc table: x | y | x−x̄ | y−ȳ | (x−x̄)² | (x−x̄)(y−ȳ) → sum last two → β̂1, β̂0 → ŷ=β̂0+β̂1x → û=y−ŷ → check Σû=0, Σxû=0 (rounding ≈0). Ex (1,2)(2,3)(3,5): β̂1=1.5, β̂0=1/3.

Interpretation templates

Slope: “A one-[unit X] increase in X is associated with a β̂1 [units of Y] higher/lower Y, on average.” (units = Y per unit X)
Intercept: fitted Y when X=0; if 0 outside data range ⇒ extrapolation, little meaning.
Prediction: ŷ(x0)=β̂0+β̂1x0 estimates E[Y|X=x0] (avg for such units, not each one). Change: Δŷ = β̂1·Δx. Beware x0 outside observed range.
Not causal because: no random assignment; selection/confounders in u (ability, motivation, income); reverse causality; small n.

Reading R output

Intercept & slope “Estimate” column ⇒ ŷ = b0 + b1x. Residual df = n − 2 (2 coefs) ⇒ n = df + 2. Class-size: Score^ = 698.93 − 2.28·STR, df 418 ⇒ n=420; STR 22→18: +9.12 pts (not proven causal).

R² = SSE/SST = 1 − SSR/SST ∈[0,1] = share of sample variation in Y explained by the fitted line (in-sample, descriptive; low R² ≠ zero slope; high R² ≠ causal). R²=.05124 ⇒ STR explains ≈5.1% of score variation; 94.9% in residuals. SST=Σ(y−ȳ)², SSE=Σ(ŷ−ȳ)², SSR=Σû², SST=SSE+SSR. Simple reg: R² = r². SER=√(SSR/(n−2)) = typical residual size (Y units).
